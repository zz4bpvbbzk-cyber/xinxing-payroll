# xinxing-payroll — 國小教務處薪資清冊生成系統

高雄市新興國小教務處的鐘點費清冊產線:每學期自動生成**固定節數、超鐘點、直播共學、越南語教支、短代**五種清冊(Excel),版型與學校原始檔逐格一致,內建三道驗證(版型守衛、fixtures 地面真值、結構檢查),全過才交付。

> 設計動機:清冊攸關薪資,不能錯;但每月手算費時。本系統把「會變的」(人員/課表/行事曆/單價)放進 Excel 設定檔,把「不變的」(算法/規則)寫進程式,以「**原檔填值**」方式輸出——產出就是學校原本的清冊檔,只填好數字,格式零改動。

## 檔案結構

```
SKILL.md                 全部校內規則鐵律 + 每學期標準流程(給 AI 或人類讀)
scripts/gen.py           生成器本體:python3 gen.py --config <設定檔.xlsx>
scripts/new_config.py    建立新學期空白設定檔
scripts/make_calendar.py 學期起訖+放假日 → 設定檔「行事曆」
scripts/import_json.py   排課系統 JSON → 設定檔「節次課表」+ 排除命中檢查
manual.html              圖文使用手冊(瀏覽器開啟)
```

> 本倉庫**不含**貴校的清冊範本與人員設定檔(含帳號等個資,請自行保管)。首次使用請放入你校的五張原始清冊 Excel 當範本(templates/),並建立自己的設定檔。

## 快速開始

```bash
python3 scripts/new_config.py --config config/config-116-2.xlsx --year 116 --sem 2 \
  --months 2,3,4,5,6 --start 2027-02-22 --end 2027-06-30
python3 scripts/make_calendar.py --config config/config-116-2.xlsx \
  --start 2027-02-22 --end 2027-06-30 --holidays "2027-03-01=和平紀念日補假,2027-04-30=勞動節補假,2027-06-09=端午節"
python3 scripts/import_json.py --config config/config-116-2.xlsx --json 排課.json --target 張三,李四,王五
python3 scripts/gen.py --config config/config-116-2.xlsx
```

輸出:`out/116-2/<月>/115年X月-○○清冊.xlsx` × 每月 5 張 + `驗算報告-116-2.xlsx`。

## 核心規則(詳見 SKILL.md)

| 清冊 | 算法 |
|---|---|
| 固定節數(兼任) | 課表**每一節次 × 該月該星期之上課日數**加總(非均攤) |
| 超鐘點(正式,週次制) | 含上課日的週算 1 週,國定假日不扣 |
| 直播共學 | 有上課才支薪:該月協同日為上課日的次數 |
| 越南語教支 | 每個上課日一列、逐日列印 |
| 短代 | 產空白版型;鐘點 405/節,全日代理走薪點制人工填 |
| 跨月 | 12 月關帳(只算到上限日,提早送會計),12 月下旬自動併入隔年 1 月;所有清冊標題附計費起訖日 |
| 節次排除 | 某節次由其他單位(如輔導處)支應:粒度到單一節次;固定節數扣節、超鐘點整列移除 |

## 驗證機制

1. **版型守衛**:輸出 vs 原始範本逐格比對,僅資料格與標題允許不同
2. **fixtures**:使用者核對過的月份寫入 `fixtures.json`,之後任何重跑數字不符即擋下
3. **結構檢查**:插列(越南語>17節)後合併儲存格與總計列位置驗證
